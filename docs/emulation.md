# Emulation

We will be using randomized ROM files provided by yours truly, using emulators available as phone apps. You can of course, play on the computer with other emulators if you'd prefer, I just figure most people are gonna be using their phones haha.

## iOS
Available for iOS is Delta! You can find it here: 
<https://apps.apple.com/us/app/delta-game-emulator/id1048524688>

Really easy, you open up the app, add a file from the top right + icon.
